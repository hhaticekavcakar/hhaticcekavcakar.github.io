Converting Process Analysis and Optimization, Alkim Kağıt

IE 3524 Integrated Manufacturing Systems

An analysis of the paper slitting process at Alkim Kağıt, aimed at reducing trim loss and setup time by improving how rolls are cut and sequenced.

My contribution

  • Analyzed the paper slitting process.
  • Built an Excel Solver linear programming model and a 2×2 Design of Experiments to evaluate cutting and sequencing strategies.

Results

  • Trim loss reduced from 4.50% to 4.20%.
  • Setup time reduced from 105 to 45 minutes (57% reduction).

Tools and methods

  • Excel Solver
  • Linear programming
  • Design of Experiments
  • Process analysis
  • Project report (PDF)
