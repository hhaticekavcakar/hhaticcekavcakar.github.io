# Videos

Put your project videos (MP4 format) in this folder, for example `project-1-demo.mp4`.

- Keep each file under 25 MB (GitHub's limit for uploading through the website).
- For longer videos, upload them to YouTube as "Unlisted" and use the YouTube embed shown in `index.html` instead.
- File names are case-sensitive on GitHub Pages: `Demo.mp4` and `demo.mp4` are different files.
